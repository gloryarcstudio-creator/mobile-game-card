# Обработка арта из Higgsfield

1. `python3 -I build_assets.py <папка с файлами> <репозиторий> [фильтры]` вырезает пурпурный фон, подгоняет размеры, собирает раскадровки врагов из роликов и сохраняет webp в `assets/`. Фильтр — вид (`enemy`, `anim`, `relic`, `card`…) или id (`inkcat`, `bell`). Файлы из `redo_ids.txt` рядом с папкой исходников пропускаются.
2. `python3 -I gen_manifest.py <репозиторий>` пишет `js/assets.js` — список готовых картинок. Чего нет в списке, игра рисует прежним SVG. Там же `foot`: где у каждого врага ноги (доля высоты картинки), по ней игра ставит врага на землю.
3. `python3 -I build_pub.py <папка>` собирает страницу для артефакта и кладёт рядом `assets/`.

Нужны Python 3 с numpy и Pillow, а для роликов ffmpeg.
